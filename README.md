## 🌟 Overview

AI Study Tracker is an intelligent productivity platform designed for students, developers, and lifelong learners.

Instead of simply recording study hours, the application leverages AI-driven insights to help users:

✅ Monitor study consistency  
✅ Track productivity trends  
✅ Analyze learning patterns  
✅ Generate personalized recommendations  
✅ Improve academic performance

Whether you're preparing for placements, competitive exams, certifications, or university coursework, AI Study Tracker helps transform study data into actionable insights.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/parasaramsrivatsav/AI_Study_Tracker.git
```

## Navigate

```bash
cd AI_Study_Tracker
```

## Install Dependencies

```bash
npm install
```

## Run Project

```bash
npm run dev
```

## Build Production Version

```bash
npm run build
```
